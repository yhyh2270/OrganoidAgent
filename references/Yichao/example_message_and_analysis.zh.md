## 关键信息提炼

Yichao 实际上传达了几个非常重要的标注标准：

1. 不能只看荧光强度。
   强荧光不等于目标细胞，背景和杂质也可能比细胞更亮。

2. 目标必须同时满足“形态正确”和“荧光合理”。
   也就是说，算法不能只做荧光阈值检测，而必须引入形态约束。

3. 真正的目标细胞有明确形态学特征。
   Yichao 指出的目标细胞特征是：
   - 位于外周一圈
   - 形状偏长条形
   - 边界清楚
   - 很多细胞内部，尤其靠边缘位置，会有一点空洞感

4. 中间一整团圆的强荧光区域不是目标细胞。
   这类区域更像是杂质、背景、或者被细胞裹挟的非目标成分。

5. 现有数据中的阳性细胞数量偏少。
   因此如果后面模型或规则不稳定，Yichao 可以额外提供一组“明确阳性”的对照图像。

## 对算法设计的直接影响

这段消息意味着当前任务不应被理解成“从荧光里找最亮的区域”，而应该被理解成：

- 在明场和荧光配对图中，识别具有正确细胞形态的目标结构
- 同时排除高亮但不符合细胞形态的背景或杂质

因此，后续算法更适合采用“形态优先、荧光辅助”的策略，而不是“荧光优先、形态补充”。

## 建议的判别规则

对于单个候选区域，建议优先考虑以下正向标准：

- 候选区域位于类器官或细胞群的外周
- 轮廓细长，而不是大而圆的一整团
- 边界清晰
- 存在一定的环状、空腔状、或中间略空的结构特征
- 在明场中也能看到与该轮廓对应的细胞边界

同时加入以下负向排除标准：

- 区域虽然荧光很强，但形态是大块圆团、实心团块
- 区域位于中央一坨，不呈现外周条带状分布
- 区域边界模糊，更像一片染亮的背景
- 区域缺乏细胞级结构，只是连续荧光片状区域

## 在算法上可落地的特征

后续如果要做传统规则法、弱监督、或模型后处理，可以考虑这些特征：

- 面积
- 周长
- 长宽比
- 圆度
- 实心度
- 是否有内部空洞
- 边界清晰度
- 与外周轮廓的距离
- 明场边缘与荧光边缘的一致性

其中最重要的是：

- 长条形 vs 圆团块
- 外周分布 vs 中央大块
- 有孔洞的边界结构 vs 实心亮块

## 对当前 pix2pix / 预测任务的启发

如果后面做 brightfield -> fluorescence 预测，这条消息同样重要：

- 模型可能会把“高亮但错误的杂质区域”也学成目标
- 因此训练时不能默认所有强荧光都是真正的正样本
- 后处理或训练筛选阶段，最好剔除明显不符合细胞形态的实例

更具体地说：

- 实例配对数据可以按形态质量再筛一层
- 对明显中央实心团块的实例，可以单独标记为可疑或排除
- 如果之后构建监督集，可以加入“目标细胞 / 杂质背景”二分类标签
